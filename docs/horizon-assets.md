# Lichii console assets

The console ships an original line icon set, a simple play glyph for titles without artwork, and synthesized interface sounds. The light and dark palettes use a blue-green focus accent. The license for the bundled artwork and audio is [GPL-3.0-or-later](../LICENSES/GPL-3.0-or-later.txt).

The focus cue is a 28 ms tap with a short, bright attack and a soft tail. Confirm rises in two quick notes, while cancel drops into a lower, dry release. Screen changes use a softer two-note entry. Context menus use a brighter descending pair, warnings use two spaced low pulses, and HOME uses a three-note return cue. All seven WAVs are generated from the oscillators and envelopes in the repository script.

Playback uses a single active sound. Focus movement can play once every 76 ms and stays quiet during action cues. An action cue can interrupt a focus tap. [Qt Multimedia QSoundEffect](https://doc.qt.io/qt-6/qsoundeffect.html)

## Local packs

Choose a local folder in the Appearance settings to install an icon or sound pack. The application stores the selected folder path in the console configuration. Keep the folder available for future sessions. Clearing the folder restores the bundled assets. Packs can supply a subset of the supported names.

For each icon, the app looks for `icons/<light-or-dark>/<name>.svg`, then the equivalent PNG, then the shared `icons/<name>.svg` or PNG. Use names from the icon row above plus `cover` for the missing-artwork image. Individual files can be up to 2 MiB and 2048×2048 pixels. Match light and dark backgrounds by providing palette-specific versions, or use a shared image with sufficient contrast in both modes.

For each sound, use `sounds/<name>.wav` with the names listed above. Use uncompressed PCM WAV, preferably mono 16-bit at 48 kHz, with each file under 512 KiB. Short sounds work best during navigation. Missing pack entries use the bundled assets.

Volume, mute, theme, and reduced motion are persisted separately from the game's audio and renderer settings. To regenerate the built-in sounds, run `python3 src/lichii_console/assets/synth_sounds.py` from the repository root.

## Profile avatars

The console includes four original geometric avatars under
`src/lichii_console/assets/avatars`, licensed GPL-3.0-or-later. Open the
profile button on HOME and choose **Change avatar** to use a preset, pick a
local file, or browse an image folder. The console copies the selected
image as the account’s avatar in the shared emulated NAND. The linked
public collection describes its images as Nintendo system artwork and
contains no redistribution license. [Avatar collection](https://github.com/vishans/Nintendo-Switch-Profile-Icons-Avatars)
